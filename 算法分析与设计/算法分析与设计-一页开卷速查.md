## 1. 渐进分析符号

- `O(f(n))`：渐近上界，增长速度不超过 `f(n)` 的常数倍
- `Ω(f(n))`：渐近下界，增长速度不低于 `f(n)` 的常数倍
- `Θ(f(n))`：渐近紧界，同时属于 `O(f(n))` 和 `Ω(f(n))`
- `o(f(n))`：严格低阶，增长速度远小于 `f(n)`
- `ω(f(n))`：严格高阶，增长速度远大于 `f(n)`

常见结论：

- `3n^2 + 2n + 1 = Θ(n^2)`
- `n = o(n^2)`
- `n^2 = ω(n log n)`

常见增长阶顺序：

`1 < logn < n < nlogn < n^2 < n^3 < 2^n < n! < n^n`

## 2. 前四章核心定义

### 2.1 算法概述

- `时间复杂度`：算法执行时间随问题规模 `n` 增长的趋势
- `空间复杂度`：算法额外存储空间随 `n` 增长的趋势
- `渐近分析`：忽略常数项和低阶项，只关注增长阶

### 2.2 递归与分治

- `递归`：函数直接或间接调用自身
- `递归出口`：终止条件，必须存在
- `分治法`：将原问题分解为若干个规模较小且相互独立的子问题，分别求解后再合并

分治三步：

`分解 -> 求解子问题 -> 合并`

主定理速套：

```text
T(n)=aT(n/b)+f(n)
比较 f(n) 与 n^{log_b a}
1. 同阶：T(n)=Θ(n^{log_b a} logn)
2. f(n) 更小：T(n)=Θ(n^{log_b a})
3. f(n) 更大：T(n)=Θ(f(n))
不熟就直接套，不在考场硬推
```

### 2.3 动态规划

- `最优子结构`：原问题最优解可由子问题最优解推出
- `重叠子问题`：相同子问题会被重复计算
- `状态`：对子问题的刻画
- `状态转移方程`：状态之间的递推关系
- `边界条件`：最小子问题的初值

DP 四步：

`定义状态 -> 写转移 -> 定边界 -> 定计算顺序`

DP 适用条件：

```text
1. 最优子结构
2. 重叠子问题
```

DP 概念题速答：

```text
最优子结构：原问题的最优解包含其子问题的最优解
重叠子问题：递归求解时，相同子问题会被反复计算
状态：对一个子问题的描述
状态转移方程：由较小子问题推出较大子问题的递推关系
边界条件：最小规模子问题的初始值
计算顺序：先算子问题，再算依赖它的大问题
```

### 2.4 贪心算法

- `贪心算法`：每一步作出当前看来最优的选择，希望得到全局最优解
- `贪心选择性质`：局部最优选择能够导向全局最优
- `最优子结构`：贪心问题通常也具备

注意：

- `分数背包` 可贪心
- `0/1 背包` 一般不可直接贪心

贪心适用条件：

```text
1. 贪心选择性质
2. 最优子结构
```

贪心概念题速答：

```text
贪心选择性质：每一步取局部最优，最终可得到全局最优
最优子结构：问题的最优解包含子问题的最优解
贪心与 DP 区别：贪心每步直接取当前最优；DP 比较多种方案后再取最优
判断贪心先看：备选项、属性、策略、反例
```

## 4. 高频递推式 / 状态转移

- 二分查找：`T(n) = T(n/2) + O(1)`
- 归并排序：`T(n) = 2T(n/2) + O(n)`
- 汉诺塔：`T(n) = 2T(n-1) + 1`
- 钢条切割：`R[j] = max(p[i] + R[j-i]), 1 <= i <= j`
- 最大子段和：`dp[i] = max(dp[i-1] + a[i], a[i])`
- 0/1 背包：`dp[i][w] = max(dp[i-1][w], dp[i-1][w-wi] + vi)`
- LCS：
  - 若 `x[i] == y[j]`，则 `c[i][j] = c[i-1][j-1] + 1`
  - 否则 `c[i][j] = max(c[i-1][j], c[i][j-1])`
- 矩阵连乘：`m[i][j] = min(m[i][k] + m[k+1][j] + p[i-1]p[k]p[j]), i <= k < j`
- 凸多边形最优三角剖分：`t[i][j] = min(t[i][k] + t[k][j] + w(i,k,j)), i < k < j`
- 最优二叉搜索树：`e[i][j] = min(e[i][r-1] + e[r+1][j] + w[i][j]), i <= r <= j`

## 5. 最易混淆对比

| 对比项 | 区别 |
| --- | --- |
| 分治 vs 动态规划 | 分治的子问题通常独立；DP 的子问题通常重叠 |
| 动态规划 vs 贪心 | DP 会比较多种方案再取最优；贪心每步直接取当前最优 |
| 回溯 vs 分支限界 | 回溯偏找可行解/全部解；分支限界偏找最优解 |
| 0/1 背包 vs 分数背包 | 0/1 背包常用 DP/搜索；分数背包可贪心 |
| Las Vegas vs Monte Carlo | 前者结果一定正确但时间随机；后者时间受控但结果可能出错 |

## 6. 高频标准话

- 动态规划适用于具有 `最优子结构` 和 `重叠子问题` 的问题。
- 贪心算法每一步都作出 `当前看来最优` 的选择。
- 回溯法按照 `深度优先` 策略搜索解空间树。
- 分支限界法通过 `界函数` 剪去不可能产生最优解的分支。
- 随机化算法通过引入 `随机选择` 改善算法的期望性能。

## 6.1 NP / NPC / 化约

```text
P：可在多项式时间内求解的问题
NP：可在多项式时间内验证解是否正确的问题
NP-hard：至少与所有 NP 问题一样难的问题
NPC：既属于 NP，又是 NP-hard 的问题
NPC = NP ∩ NP-hard
```

证明一个问题是 NPC 的一般步骤：

```text
1. 证明该问题属于 NP
2. 选一个已知 NPC 问题
3. 将已知 NPC 问题多项式时间化约到该问题
```

高频结论：

```text
第一个 NPC 问题：SAT
常见 NPC：3-SAT、团问题、点覆盖、Hamilton 回路、子集和
若某 NPC 问题可在多项式时间内求解，则 P = NP
```

## 7. 必带 C++ 模板

### 7.1 二分查找

```cpp
int binarySearch(vector<int>& a, int target) {
    int left = 0, right = (int)a.size() - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] == target) return mid;
        else if (a[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

要点：

- 要求 `数组有序`
- 时间复杂度 `O(logn)`，空间复杂度 `O(1)`

### 7.2 0/1 背包

```cpp
int knapsack01(vector<int>& weight, vector<int>& value, int W) {
    int n = weight.size();
    vector<vector<int>> dp(n + 1, vector<int>(W + 1, 0));

    for (int i = 1; i <= n; i++) {
        for (int w = 0; w <= W; w++) {
            dp[i][w] = dp[i - 1][w];
            if (w >= weight[i - 1]) {
                dp[i][w] = max(dp[i][w],
                               dp[i - 1][w - weight[i - 1]] + value[i - 1]);
            }
        }
    }
    return dp[n][W];
}
```

要点：

- `dp[i][w]`：前 `i` 个物品在容量 `w` 下的最大价值
- 转移分两种：`不选` / `选`
- 时间复杂度 `O(nW)`，空间复杂度 `O(nW)`

### 7.3 回溯通用框架

```cpp
void dfs(int k) {
    if (到达叶子) {
        记录答案;
        return;
    }
    for (每个可选决策) {
        if (满足约束) {
            做选择;
            dfs(k + 1);
            撤销选择;
        }
    }
}
```

要点：

- 核心是 `试探 -> 递归 -> 回退`
- 常用于 `全排列`、`N 皇后`、`子集和`

### 7.4 分支限界速记

```text
目标：求最优解
核心：在搜索过程中用“界函数”提前剪枝
常见模型：
1. 子集型：选 / 不选
2. 排列型：当前位置放谁
程序填空先看：
1. 参数表示什么状态
2. 当前层表示处理到哪个对象
3. 界函数在入队/递归前还是扩展时判断
4. 当前最优值 best 是否参与剪枝
```

常见界：

```text
装载/背包：当前值 + 剩余可能最大值
最短路：当前路径长度
TSP/最大团：当前部分解 + 理论上界
```

通用伪代码：

```text
best = 当前已知最优
把根结点放入活结点表
while 活结点表非空:
    取出一个结点 u
    if u 的界不可能优于 best: continue
    扩展 u 的子结点
    对每个子结点 v:
        先算 bound(v)
        若 v 还有希望，加入活结点表
        同时用可行解更新 best
```

Bound 口诀：

```text
最大化问题看上界 upper bound
最小化问题看下界 lower bound
0-1 背包：按“分数背包”估上界
最大团：当前团大小 + 剩余顶点数
TSP：当前路径长度 + 剩余最小可能代价
装载：当前载重/价值 + 剩余可装上限
```

## 8. 考前 30 秒提醒

- 二分查找要求 `有序`
- 快速排序平均 `O(nlogn)`，最坏 `O(n^2)`
- 归并排序稳定，堆排序不稳定
- `0/1 背包 = O(nW)`，不能直接简化成 `O(n)`
- Dijkstra 要求 `边权非负`
- 回溯 / 分支限界常为指数级或阶乘级
- 随机化改善 `期望性能`，不保证每次都最好
