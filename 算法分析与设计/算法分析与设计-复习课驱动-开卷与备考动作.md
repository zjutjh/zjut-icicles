## 2. 开卷页必须新增的 5 块

## 2.1 题型提醒块

直接写一小块提醒自己：

```text
题型：判断 / 选择 / 程序填空 / 简答
程序填空重点：认模型、认参数、认递归逻辑
```

原因：

- 这能防止你考前把注意力全放到“背定义”或“刷整题”上

## 2.2 主定理 / 递归式块

老师已经明确给了开卷信号，这块要带：

```text
T(n)=aT(n/b)+f(n)
比较 f(n) 与 n^{log_b a}
三种情形直接写结论
```

再补一行：

```text
不熟就直接套，不在考场硬推
```

## 2.3 贪心策略块

老师对贪心的口风非常统一，开卷页要写成“判断框架”而不是例题堆砌：

```text
贪心先看：
1. 备选项是什么
2. 属性是什么
3. 贪心策略按哪个属性取
4. 能否用反例排除错误策略
```

再补两个典型提醒：

```text
活动安排：结束时间最早
Dijkstra：只适用于边权非负
Bellman-Ford：不在大纲，降级
```

## 2.4 动态规划块

这是最需要加强的一块。

开卷页里不能只放公式，要放老师强调的“构造方法”：

```text
DP先看：
1. 状态变量索引的是对象，还是对象属性/前缀
2. 前缀型还是中缀型
3. 当前动作是什么（选/不选、连接等）
4. 由动作推递推式
```

背包块建议单独补：

```text
背包：i=物品前缀，j/x=容量前缀
核心动作：第 i 件放 / 不放
变形题仍然重要
二维 DP 比一维更危险
```

## 2.5 回溯 / 分支限界 / 随机化块

这三章考试方式很像“概念 + 程序填空”，开卷页必须写成模型导向。

建议新增：

```text
回溯/分支限界先判定：
1. 子集问题：选/不选
2. 排列问题：当前位置放谁
```

再补：

```text
程序填空看参数：
参数表示什么
递归时变大还是变小
共同目标：更接近子问题
```

随机化块补：

```text
随机快排：随机支点，平均 O(nlogn)
20/80 视为好划分
随机选择第 k 小：Las Vegas，结果一定对，平均 O(n)
Monte Carlo：结果可能错
```

## 3. 备考时间分配建议

按老师口风，建议优先级如下。

## 第一层：必须先稳住

- 动态规划
- 回溯法
- 分支限界法
- 程序填空模板

## 第二层：需要会辨析

- 贪心算法
- 随机化算法

## 第三层：稳基础分

- 渐进分析
- 主定理
- NP / NPC

## 4. 接下来继续学习时的顺序

建议后面按这个顺序学：

1. `动态规划`
   - 一维 DP 快速复位
   - 二维 DP
   - 背包变形
   - 递推式构造训练
2. `回溯法`
   - 子集 vs 排列
   - 程序填空
3. `分支限界法`
   - 和回溯并排对照
   - 背包 / TSP / 最大团
4. `随机化算法`
   - 快排随机支点
   - Las Vegas / Monte Carlo
5. `贪心算法`
   - 备选项 / 属性 / 策略 / 反例

## 5. 继续带学时的规则

后面我再继续带你学时，会默认遵守这 6 条：

1. 优先讲 `老师明确说是重点` 的章节。
2. 代码讲解优先用 `程序填空视角`。
3. DP 会重点盯：
   - 状态定义
   - 变量意义
   - 递推构造
4. 回溯/分支限界会重点盯：
   - 子集/排列判断
   - 参数含义
   - 模板识别
5. 随机化会重点盯：
   - 随机支点
   - 20/80
   - Las Vegas / Monte Carlo
6. 不在大纲的内容默认降级，不再抢你时间。
