1. 本学期的试卷与上学期重合度极高，选择题有4-5道重复，简答题重复问了辛亥革命的意义和为什么中国共产党成立是开天辟地的大事件。
因此，准备此门考试的额时候建议参考一下往年试卷。
2. 本人根据老师画的重点和这个仓库里的资料新整理了一份更加全面一些的复习材料，即“中国近史纲 考前突击 终稿”，可参照使用
3. 如果你是历史选考生，这门课基本上是不需要复习的，难度远低于高考卷，而知识点几乎全部被选考范围覆盖了。
发的一个近代史的题库的单选题可以着重做一下，期末考试的单选题貌似几乎全部都是选自这里面，因为考试题型只有单选题和大题所以只做题库的单选题即可，大题可以参考当年老师画的重点
