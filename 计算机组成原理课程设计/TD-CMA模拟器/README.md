# TD-CMA 3.3 复杂模型机模拟器

这是一个面向《计算机组成原理实验教程》第 3 章 3.3“带中断功能的复杂模型机”的本地模拟器。程序会解析 TD-CMA 联机软件常见的 txt 文件格式，并按 `$M` 微控存中的 24 位微指令驱动数据通路执行，而不是直接写死机器指令。

## 运行方式

### 双击启动

最方便的方式是直接双击项目目录里的：

```text
TD-CMA-Simulator.app
```

如果要把模拟器发给别人，建议先生成自包含 app：

```bash
/usr/bin/python3 build_macos_app.py
```

然后发送或双击：

```text
dist/TD-CMA-Simulator.app
```

如果 macOS 提示不能打开，也可以双击备用脚本：

```text
启动TD-CMA模拟器.command
```

启动后浏览器会自动打开模拟器页面。关闭 `.command` 打开的终端窗口，或在终端里按 `Control-C`，即可停止服务。

### 命令行启动

```bash
/usr/bin/python3 web_app.py --open
```

然后在浏览器打开：

```text
http://127.0.0.1:8765
```

Web 版只使用 Python 标准库，不需要 Flask、npm 或 Tkinter。旧的 Tkinter 入口仍保留在 `app.py`，但推荐使用 Web 入口。

如果提示端口被占用，可以直接访问上面的地址看看是否已有服务在运行，或换端口启动：

```bash
/usr/bin/python3 web_app.py --port 8766
```

双击入口默认使用 `--auto-port --open`，如果 `8765` 已被占用，会自动尝试后续端口并打开对应页面。

启动后点击“打开文件”，可先选择：

```text
examples/interrupt_demo.txt
```

数字循环控制修正版在：

```text
examples/TD_CMA_interrupt_loop_control_fixed.txt
```

## 界面功能

- “打开文件”：加载包含 `$P` 主存和 `$M` 微控存记录的 txt。
- “连续运行”：浏览器周期性请求后端按机器指令连续执行。
- “终止/复位”：停止运行，并把主存/微控存恢复到已加载文件，寄存器清零。
- “单指令运行”：执行下一条机器指令对应的一段微程序。
- “触发中断”：用当前 IN 单元值作为输入数据，同时置位 8259 的 IR0 请求。
- “清空日志”：清除当前页面中的运行日志。
- IN 单元按 8 个外部开关模拟，只能由用户手动修改；程序运行和复位不会自动刷新它。
- 状态区显示 R0-R3、PC、IR、AR、SP、FZ、FC、EI、INTR、微地址 uAR 和 OUT。

## 文件格式

示例：

```text
$P 00 60 ; LDI R0,13H
$P 01 13
$M 00 0001C1 ; NOP
$M 01 000102 ; P<4>
```

解析规则：

- `$P` 后为 8 位主存地址和一个或多个 8 位数据。
- `$M` 后为 6 位十六进制微指令，也兼容写成 3 个字节。
- 兼容同一物理行里连续出现多个 `$P`/`$M` 记录，也兼容 `$M30 001604` 这类标签和地址紧贴的写法。
- `;`、`//`、`#` 可用于注释；如果注释文本后面又出现合法 `$P`/`$M` 记录，模拟器会按 TD-CMA 联机软件习惯继续识别后续记录。

## 已实现部件

- 8 位主存 MEM、256 字微控存、微地址寄存器。
- IR、PC、AR、R0-R3、A/B 暂存器。
- ALU 的 S3-S0 功能，含 FZ/FC 更新。
- IN/OUT 单元和 I/O 地址译码。
- 简化 8259：ICW1/2/3/4、OCW1、IR0-IR7、INTR、两次 INTA#、向量号输出。
- EI 中断允许触发器。
- R3 作为 SP 的 PUSH、POP、IRET 栈流程。
- P<1>、P<2>、P<3>、P<4> 微程序判别条件。

## 当前合理假设 / TODO

- 教材微指令表第 23 位标为 `M23`，未在 3.3 页内明确说明。本模拟器暂按 ALU 的 `CN` 输入处理，用于带进位移位和 `S=1000` 置 FC。标准 3.3 示例微程序未使用该位。
- 微控存可加载 `00-FF` 地址；教材 3.3 微指令下址字段仍为 `MA5-MA0` 6 位，所以标准微程序入口和分支仍按 `00-3F` 执行。
- 某些真机验证过的 txt 只写入本次实验改动过的微控存单元，依赖板上原有的直接寻址入口 `3C=006D5C`。模拟器检测到这种教材微程序布局且 `3C` 缺失时会补入该入口，并在加载日志里提示 WARN。
- 8259 只实现本实验需要的核心行为；OCW2/OCW3、优先级轮转、嵌套中断等完整 8259 细节保留为后续扩展。
- 8253 端口按未用设备处理，读返回 `00`，写仅记录日志。
