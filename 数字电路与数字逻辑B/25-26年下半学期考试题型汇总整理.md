## 老师图片 1-5 对应题型

### 图片 1：74LS161 可控计数器

题面要点：A=1 时为 12 进制计数器；A=0 时为 10 进制计数器。  

复习模板：

- 识别 74LS161 的计数使能、并行装入、清零端。
- 看组合逻辑如何译码终端状态。
- 判断什么时候回到 0000。
- 最后说明模数。

答题句式：

```text
当计数到终端状态时，译码输出使装入/清零控制端有效，
下一时钟后计数器回到 0000，所以循环状态数为 N，是 N 进制计数器。
```

### 图片 2：两个 JK 触发器实现时序电路

题面要点：根据卡诺图化简得到两个触发器的状态方程和输出方程，再用 JK 触发器实现。

复习模板：

```text
写状态方程 Q1+、Q0+
写输出方程 Z
由 JK 激励表反推 J0 K0 J1 K1
画电路
```

必背：

```text
JK 特性方程：Q+ = JQ' + K'Q
```

### 图片 3：555 占空比可调多谐振荡器

题面要点：已知 `f=10kHz`、`q=0.2`、`C=0.01uF`，求 `R1`、`R2`。

图上公式：

```text
T1 = 0.7 R1 C
T2 = 0.7 R2 C
T = T1 + T2
f = 1/T
q = T1/T
```

算题模板：

```text
T = 1/f
T1 = qT
T2 = T - T1
R1 = T1/(0.7C)
R2 = T2/(0.7C)
```

该图答案：

```text
T = 100 us
T1 = 20 us
T2 = 80 us
R1 ≈ 2.86 kΩ
R2 ≈ 11.43 kΩ
```

### 图片 4：CMOS 复合门电路

题面要点：从 CMOS 管网络读逻辑表达式。图中给出类似：

```text
Y3 = (AB)' · (CD)' + EN
```

复习模板：

- NMOS 下拉网络导通对应输出被拉低。
- PMOS 上拉网络导通对应输出被拉高。
- 串联对应“与”，并联对应“或”。
- 读表达式时注意反相关系。

这类题可能放在选择、简答或小分析题，不是后半部分主战场，但能拿分。

### 图片 5：101 序列检测 Moore 状态机

题面要点：串行输入 X 中连续出现 101 时，另一个串行输出 Y 当前状态输出，其他情况输出低电平。

状态定义：

```text
S0：未匹配
S1：已匹配 1
S2：已匹配 10
S3：已匹配 101，输出 1
```

状态编码：

```text
S0=00, S1=01, S2=10, S3=11
```

Moore 型转移可按：

```text
S0 --0--> S0
S0 --1--> S1
S1 --0--> S2
S1 --1--> S1
S2 --0--> S0
S2 --1--> S3
S3 --0--> S2
S3 --1--> S1
```

输出：

```text
S3 输出 1，其余状态输出 0
```

## 简答题可背模板

### 同步时序电路分析步骤

```text
先写输出方程和触发器驱动方程；
再代入触发器特性方程得到状态方程；
然后列状态转换表，画状态图；
最后根据状态循环和输出判断电路功能，并检查是否能自启动。
```

### Moore 和 Mealy 区别

```text
Moore 型输出只与当前状态有关，输出标在状态上；
Mealy 型输出与当前状态和输入都有关，输出标在状态转移边上。
Moore 型输出较稳定，但状态数可能多；Mealy 型响应更快，状态数可能少。
```

### 555 多谐振荡器工作过程

```text
电容电压低于 1/3VCC 时，触发比较器使锁存器置位，输出为高，放电管截止，电容充电；
电容电压高于 2/3VCC 时，阈值比较器使锁存器复位，输出为低，放电管导通，电容放电；
电容在 1/3VCC 和 2/3VCC 之间反复充放电，形成周期性矩形波。
```

### ADC 基本过程

```text
A/D 转换通常包括采样、保持、量化和编码。
采样把连续信号变成离散时间信号，保持保证转换期间电压稳定，
量化把连续幅值归入有限等级，编码把量化结果转成二进制代码。
```
